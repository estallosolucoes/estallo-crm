# 09 — Anti-patterns do Design System Estallo

Referência: [padrão vigente](README.md). Estas regras substituem restrições visuais herdadas.

| Evitar                                                                     | Aplicar                                              |
| -------------------------------------------------------------------------- | ---------------------------------------------------- |
| Restaurar cores ou fontes antigas a partir de specs, handoffs ou `/design` | Blue / Green / Ink e Sora / Manrope / JetBrains Mono |
| Marca ou tema diferente por organização                                    | Identidade fixa Estallo; empresa ativa como contexto |
| Hex e fontes soltos em componentes                                         | Tokens e componentes compartilhados                  |
| Distorcer ou redesenhar o logotipo                                         | Geometria e variações oficiais                       |
| Cor como único indicador                                                   | Texto, ícone e nome acessível                        |
| Branco sobre uma cor de marca sem medir contraste                          | Variação operacional legível, sem mudar o logo       |
| Efeito que prejudica leitura                                               | Composição Blue → Green onde serve ao conteúdo       |
| Ações principais concorrentes ou próximo passo oculto                      | Hierarquia e retorno visível                         |
| Movimento obrigatório ou distração contínua                                | Movimento funcional com redução de movimento         |
| Texto pequeno para acomodar conteúdo                                       | Layout responsivo e densidade adequada               |
| Erro genérico ou promessa sem comprovação                                  | Resultado, contexto preservado e como continuar      |
| Descrever todos os módulos como redesenhados                               | Registrar escopo entregue e próximas etapas          |

Não há proibição absoluta de gradientes, azuis saturados ou JetBrains Mono: são recursos do Brand System Estallo. O critério é identidade, utilidade e acessibilidade.
